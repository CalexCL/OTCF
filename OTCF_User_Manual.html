Overtime Claim Form (OTCF) — User Manual

This manual is provided in English and Simplified Chinese (中文), in separate sections below.

English 简体中文

1. Overview

The Overtime Claim Form (OTCF) is a digital version of the paper OTCF used to record an employee's overtime work and request approval and payment for OT hours. It opens directly in a web browser — no installation or login is required.

2. Getting Started

Open the OTCF HTML file in any modern browser (Chrome, Edge, or Safari). The form works fully offline, except for the Print/Save PDF and Share to WhatsApp features, which need an internet connection the first time the page loads (to fetch the PDF tools).

3. Filling in Employee Details

  • Name — select from the dropdown. If your name isn't listed, choose "+ Add new...", type it in, and it will be saved for future use.
  • Designation — same as Name.
  • Department — same as Name (defaults to "HQ").
  • Submission Date — defaults to today; click to change.
  • Month / Year — default to the current month and year; can be changed. Changing either regenerates the daily table below.
  • No. of days in mth — calculated automatically based on Month/Year; cannot be edited directly.

4. Working Hours

Working Hour From / To (default 9:00 AM – 6:00 PM) — enter your normal working hours here. The form uses this range to check that your OT claims do not overlap your normal working hours.

5. Filling the Daily Table

  • Date / Day — generated automatically from the Month and Year above; no manual entry needed.
  • PH (Public Holiday) — tick this box if the date is a public holiday. The whole row turns light red, and Claim Type is automatically set to "Public Holiday".
  • Claim Type — choose Normal, Off Day, Rest Day, or Public Holiday for each day you are claiming OT.
  • OT Hrs From / To — enter the start and end time of the overtime worked.
  • Total Hrs — calculated automatically from From/To, but can be edited manually if needed.
  • Remarks — optional free text for additional notes (e.g. reason for OT, project name).

6. Color Indicators

Light blue row — weekend (Saturday/Sunday).
Light red row — Public Holiday (PH ticked).
Dark red cell (OT From/To/Total Hrs) — the claimed OT time overlaps your normal Working Hours; flagged as an error to fix before submission.

7. Adding New Dropdown Entries

  1. Open the Name, Designation, or Department dropdown.
  2. Select "+ Add new...".
  3. Type the new value into the pop-up box and confirm.

The new value is saved in your browser's local storage and will appear in the dropdown next time you open the form on the same device and browser.

Note: Added entries are stored locally on your device only — they will not appear if you open the form on a different device or browser.

8. Printing / Saving as PDF

Click "Print / Save PDF" at the top of the form. In the print dialog that opens, choose a printer, or select "Save as PDF" as the destination. The layout is formatted to fit a single A4 page.

9. Sharing to WhatsApp

Click "Share to WhatsApp". On a mobile browser, this generates a PDF copy of the filled form and opens your phone's native share menu — select WhatsApp to send it directly. If your browser does not support direct sharing, the PDF is downloaded instead; you can then attach it manually in WhatsApp.

10. Submission Reminders

  • OT Claim forms should be submitted on the last day of each month to HR.
  • For late submission, payment will be made the following month.

11. Troubleshooting

  • Dropdown not saving new entries — make sure your browser allows local storage (Incognito/Private mode clears storage when the window closes).
  • Table not updating after changing Month/Year — click outside the field to confirm the change.
  • Total Hrs not calculating — make sure both the From and To times are filled in.

加班申请表 (OTCF) — 用户手册

版本: OTCF v.2026.06.29-18:00

1. 概述

加班申请表(OTCF)是纸质版OTCF的数字化版本,用于记录员工的加班工作,并申请加班费的批准与发放。表格可直接在网页浏览器中打开使用,无需安装或登录。

2. 开始使用

请使用任何现代浏览器(Chrome、Edge 或 Safari)打开 OTCF 的 HTML 文件。表格可完全离线使用,唯独"打印/保存PDF"与"分享至WhatsApp"功能在首次加载页面时需要网络连接(用于加载PDF生成工具)。

3. 填写员工资料

  • 姓名 — 从下拉列表中选择。如果列表中没有您的姓名,请选择"+ 添加新项...",输入后系统会保存供下次使用。
  • 职位 — 操作方式与姓名相同。
  • 部门 — 操作方式与姓名相同(默认为"HQ")。
  • 提交日期 — 默认为当天,可点击更改。
  • 月份 / 年份 — 默认为当前月份与年份,可自行更改。更改后,下方的每日表格会自动重新生成。
  • 当月天数 — 根据月份/年份自动计算,无法手动编辑。

4. 工作时间

工作时间(从 / 到)(默认为上午9:00至下午6:00)— 请在此填写您的正常上班时间。系统将以此核对您申请的加班时间是否与正常上班时间重叠。

5. 填写每日表格

  • 日期 / 星期 — 根据上方的月份与年份自动生成,无需手动输入。
  • 公假(PH) — 如该日为公共假期,请勾选此项。该行将整行显示为浅红色,且"申请类型"会自动设为"Public Holiday"。
  • 申请类型 — 为每个申请加班的日期选择 Normal(平日)、Rest Day(休息日)或 Public Holiday(公假)。
  • 加班时间(从 / 到) — 填写加班的开始与结束时间。
  • 总时数 — 根据"从/到"时间自动计算,如有需要可手动修改。
  • 备注 — 选填,用于补充说明(如加班原因、项目名称等)。

6. 颜色说明

浅蓝色行 — 周末(星期六/星期日)。
浅红色行 — 公共假期(已勾选PH)。
深红色格(加班从 / 到 / 总时数) — 申请的加班时间与正常工作时间重叠,系统会标记为错误,请于提交前更正。

7. 新增下拉选项

  1. 打开姓名、职位或部门的下拉列表。
  2. 选择"+ 添加新项..."。
  3. 在弹出框中输入新内容并确认。

新内容将保存在您浏览器的本地存储中,下次在同一设备及浏览器打开表格时会显示在下拉列表中。

注意:新增内容仅保存于本机,若在其他设备或浏览器打开表格,将不会显示。

8. 打印 / 保存为PDF

点击表格顶部的"Print / Save PDF"按钮。在弹出的打印对话框中选择打印机,或选择"另存为PDF"作为输出方式。表格版面已调整为可容纳于一张A4纸内。

9. 分享至WhatsApp

点击"Share to WhatsApp"按钮。在手机浏览器中,系统会生成已填写表格的PDF文件,并打开手机的原生分享菜单,选择WhatsApp即可直接发送。若浏览器不支持直接分享,系统将自动下载PDF文件,您可手动在WhatsApp中添加附件发送。

10. 提交须知

  • 加班申请表应于每月最后一天提交给人力资源部(HR)。
  • 逾期提交的表格,加班费将于次月发放。

11. 常见问题

  • 下拉列表无法保存新增内容 — 请确认浏览器允许本地存储功能(无痕/隐私模式下,关闭窗口后数据会被清除)。
  • 更改月份/年份后表格未更新 — 请点击该字段外的区域以确认更改。
  • 总时数未自动计算 — 请确认"从"与"到"时间均已填写。
